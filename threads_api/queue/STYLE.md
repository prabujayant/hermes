# House Style - owlsky17 Threads (locked from 2026-10-07)

Based on top performers (#1: 98k views; memorize-listicle family; 18/09/2026 LeetCode thread).
Use this format for EVERY thread draft unless told otherwise.

## Hook post (1/N) - ALL CAPS
- Formula: `IF YOU WANT TO <ASPIRATION>, STOP <BAD HABIT>.`
- Second line: `MEMORIZE THESE <N> THINGS:`
- End hook with counter pill: `1/5` (total = hook + replies)
- Example:
  ```
  IF YOU WANT TO BECOME A TOP 1% SOFTWARE ENGINEER, STOP SOLVING LEETCODE RANDOMLY.

  MEMORIZE THESE 7 THINGS: 1/5
  ```

## Reply posts (2/N to N-1/N) - sentence case
- 2-4 short paragraphs, one idea per post.
- Each post ends with its own counter: `2/5`, `3/5`, ...
- Concrete, opinionated, no fluff. Name exact tools/patterns/numbers.
- Example:
  ```
  Most LeetCode problems are variations of a small number of patterns.

  The skill isn't memorizing 500 solutions.

  It's recognizing which pattern you're looking at. 2/5
  ```

## Final post (N/N) - follow CTA, always
- Fixed CTA, sentence case + counter. This is non-negotiable: the last
  post is ALWAYS the follow CTA, never a comment CTA or anything else:
  ```
  I post daily breakdowns like this for backend, SQL, and interviews.

  Follow @owlsky17 so you don't miss the next one. 5/5
  ```

## Rules
- Hook CAPS, replies sentence case. Never mix.
- Counter `k/N` on EVERY post including hook and CTA.
- N = 5 total (1 hook + 3 value + 1 CTA) by default; 7 max.
- Each post ≤ 500 chars (API limit).
- Plain ASCII only: NEVER em dashes or en dashes, use commas or plain hyphens.
- Topics that win: LeetCode patterns, backend, SQL, interviews, career.
- No resume-dishonesty angles - reframe as "prove it in the interview".
